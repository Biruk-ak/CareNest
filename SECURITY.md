# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 5.x     | Yes       |
| < 5.0   | No        |

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Email **birukaklilu0110@gmail.com** with:

- Description of the issue
- Steps to reproduce
- Potential impact
- Your contact details

You should receive an acknowledgement within a few business days. Do not include real patient data (PHI) in reports — use synthetic examples only.
